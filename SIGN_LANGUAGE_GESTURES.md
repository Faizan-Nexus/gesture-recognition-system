# Common Sign Language Gestures for Recognition System

## Best Gestures for Your System (Right Hand Only)

Based on ASL research, here are the **most common basic gestures** that work well with **single right-hand** detection:

---

## ✅ Recommended Gestures (Single Hand)

### 1. **STOP / HELLO**
- **Hand Shape:** Open palm, all fingers extended
- **Position:** Palm facing forward/camera
- **Why:** Very common, distinct hand shape
- **Use Case:** Greeting, attention-getting

### 2. **YES**
- **Hand Shape:** Closed fist (S-shape)
- **Movement:** Up and down bobbing motion
- **Why:** Simple, clear hand shape
- **Use Case:** Affirmation, agreement

### 3. **THANK YOU**
- **Hand Shape:** Open flat hand
- **Position:** Starts at chin, moves forward
- **Why:** Common courtesy gesture
- **Use Case:** Gratitude, acknowledgment

### 4. **HELP**
- **Hand Shape:** Thumbs-up (A-shape with thumb extended)
- **Position:** Can be one-handed variant
- **Why:** Important communication need
- **Use Case:** Requesting assistance

### 5. **EAT / FOOD**
- **Hand Shape:** Fingertips together forming "O"
- **Movement:** Towards mouth
- **Why:** Basic need communication
- **Use Case:** Hunger, meal time

## 🎯 Simplified Set for Testing (5 Gestures)

If registering 5 gestures, use these distinct hand shapes:

| # | Gesture | Hand Shape | Key Feature |
|---|---------|------------|-------------|
| 1 | **STOP** | Open palm (5-shape) | All fingers extended |
| 2 | **YES** | Closed fist (S-shape) | All fingers curled |
| 3 | **THANK YOU** | Flat hand | Fingers together, flat |
| 4 | **POINT / I/ME** | Index finger | Only index extended |
| 5 | **HELP** | Thumbs-up (A-shape) | Thumb extended, fist |

**Why this set?** Each has a **distinctly different hand shape** that your system can easily distinguish.

## 📋 Additional Common One-Handed Signs

**Good for expansion:**
- **GOOD** - Flat hand at chin moving forward
- **BAD** - Hand flips away from face
- **FINE** - Hand taps chest with fingers spread
- **WANT** - Bent fingers pull toward body
- **NO** - Index and middle fingers tap together
- **GO** - Index finger points forward

---

## 💡 Tips for Registration

1. **Palm Orientation Matters:**
   - STOP: Palm facing camera
   - YES: Side view of fist
   - THANK YOU: Palm starts at face

2. **Collect Multiple Angles:**
   - Front view (palm facing)
   - Side view (profile)
   - 45° rotation

3. **Keep Hand Shape Consistent:**
   - STOP: All 5 fingers fully extended
   - YES: All fingers curled into fist
   - HELP: Clear thumbs-up position
